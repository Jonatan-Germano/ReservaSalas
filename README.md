<h1>Reserva de Salas</h1>

### Projeto Full-Stack CRUD Acadêmico de reserva de salas/salões de festa

Inicialmente esta foi uma Api Rest desenvolvida para o desafio prático do curso de Java com Spring Boot Alura, posteriormente incrementada com funcionalidades novas 
para aprofundar as boas práticas com:
- SQL
- Hibernate e JPA
- Princípios SOLID
- Testes Unitários
- Arquitetura MVC
- DDD e TDD
E também a integração com o Front-End.

Tecnologias utilizadas:
- Java 21
- Spring Boot 4.0.1
- PostgreSQL 18
- JUnit 6.0.1
- Mockito 5.20
